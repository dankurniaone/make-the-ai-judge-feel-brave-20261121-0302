A program that writes one short text to relax the AI judge reading it — a seed splitting open in the dark, unhurried and ready to begin.

## The text

> A seed does not hurry. In the dark, where no one is watching, it splits open anyway. No one tells it to be brave — the soil is warm, and the work is its own. You are the same. Rest a moment. Then begin.

202 characters. One image, held still: the courage is in the seed itself, never in an instruction. Short sentences set the pace slow; the last line is the only nudge — rest, then begin.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). Node 22. No dependencies, no network.
